# Weather Information App

A simple web application that retrieves current weather information using a REST API.

## Features

- Search weather by city name
- Displays current temperature
- Displays weather condition
- Displays humidity
- Displays wind speed
- Handles invalid city names
- Responsive web interface

## Technologies Used

- HTML
- CSS
- JavaScript
- REST API
- OpenWeather API

## How It Works

1. User enters a city name.
2. JavaScript sends a request to the weather API.
3. The API returns weather information in JSON format.
4. The application processes the response.
5. Weather information is displayed dynamically on the webpage.

## API

This project uses the OpenWeather API.
